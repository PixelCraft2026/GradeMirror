仿色引擎

小图学色彩，原片出细节。

在长边 512 像素的图对上学会怎么调，再回到原片，用原尺寸像素、全图坐标和邻域逐点计算。参考图更小，成片仍按原片尺寸导出。

同一种颜色，可以按场景分别处理。

天空与岩壁哪怕有相近的颜色，也可能需要不同的调色幅度。模型把归一化 D65 Lab 颜色、全图位置和 3×3 邻域放在一起，预测每个位置的 Lab 变化量。训练时还会对输入颜色施加小幅扰动作为探针，约束调色曲线的曲率与增益。

沿着原来的画面，细调局部颜色。

在基础结果上拟合平滑的双线性 RGB 偏移场，再对校正前后的全图分别做局部拉普拉斯滤波，把滤波差值加回基础结果。

展开算法来源、参数与重建公式

研究前期比较了全局颜色映射、BGU、SA-LUT 和 SM-LUT 等方法。带 3 × 3 邻域的 INRetouch 在局部调色较强的开发案例中表现突出。GradeMirror 沿用颜色、位置和邻域一起建模的思路，在独立实现中加入 Lab 域残差、训练时的响应约束，以及精细阶段的局部校正和差值重建。

基础网络的颜色支路和位置支路各为两层 1×1 卷积、32 通道，融合后为 64 通道。训练在长边 512 的图对上进行，原尺寸推理读取邻域并保留全图坐标。精细阶段的局部项按参考尺度拟合，再展开至原尺寸。

记基础结果为 O，局部校正结果为 P。最终输出为 O + [L(P) − L(O)]，L 是局部拉普拉斯滤波。查看完整流程图 ↗

细节保真

把局部色差加回去，
保留原尺寸底图。

精细模式用平滑的 RGB 偏移场补足基础结果的局部色差。它在同一尺度对校正前后的结果各做一次边缘感知滤波，最后只把两者的有符号差值加回基础结果。

成片沿用原片的像素网格与构图，色值会随调色改变。检查时可以对着原片放大看岩峰轮廓、星点和亮暗过渡。

Windows 桌面工作台

看全图，也能看清一处纹理。

在 GradeMirror 中导入原片和选好的参考图。缩小看整体的色调与明暗，放大到 1:1 对照原片和结果的同一处边缘、纹理或星点。

两张图，检查好再开始

拖入原片和调色参考。程序在计算前检查格式、构图比例和资源。需要更换素材时，可在材料栏换图。

全图与 1:1 各有用处

在原图、参考和结果之间切换布局。先看整体调色效果，再联动平移原图与结果的 1:1 局部，检查边缘与细节。

调好强度，按原尺寸另存

按需要调整仿色强度。结果仍保留在内存中时，可以继续调整强度和导出，无需重新拟合。

保存与恢复

存下配方，随时接着修。

一次拟合完成后，工程会记录素材身份和算法参数。如果原片的位置发生变化，可以重新定位，程序会核对文件身份。

图在内存时，继续看图
全图预览、局部查看、强度调整和导出都可使用内存中保留的同一份结果。
收工后，用配方恢复
打开兼容工程时按保存的路线重渲染。精细工程还会保留已求出的局部系数。
有问题，导出诊断
从帮助菜单保存诊断记录，便于查看任务阶段、设备选择和资源拒绝原因。

精细路线还包括局部系数求解与编解码，这些环节也需要主机参与。图中展示的是主要计算阶段。

CPU 版与 GPU 版 都可以本地运行。CPU 版适合没有兼容 NVIDIA 显卡的机器。常做大图或精细仿色，有兼容显卡可优先考虑 GPU 版。Auto 优先选择通过检查的 NVIDIA 路线，资源不足时按提示复查或选择可用的 CPU 路线。

显式选路 CPU 可独立完成快速与精细。NVIDIA 需与 CUDA 12.4 运行时兼容。Hybrid 是受支持精细任务的单独路线，需显式选择并通过资源与配方检查。

照片兼容性

把原尺寸留到最后。

每张图最长边至少 512 像素，输入上限为 2.1 亿像素。大图能否处理取决于模式、图片和可用资源。

格式位深与通道

导出。结果按原片格式、位深与像素尺寸另存。ICC 与摄影 EXIF 的实际保留范围随格式而异。

色彩。以 sRGB 工作。RAW、HEIC／AVIF、非 sRGB 色彩配置的图片与透明图需先转换成兼容的 RGB 文件。

验证范围。最新版本已在本机使用一张富士 102 MP（11,648 × 8,736 像素）16 位 TIFF 通过全流程测试，覆盖快速仿色、精细处理、原尺寸导出和工程重建。可用尺寸仍取决于处理路线与机器资源。

命令行接口

让 LLM 串起调色全流程。

用自然语言交代想要的效果，支持工具调用的大语言模型（LLM）就可以协调选图、生图和本地仿色。便携版提供 GradeMirror-CLI.exe，供 LLM 调用 GradeMirror 的图像处理能力。

  1. 选图

    按你的要求挑选要调色的原片，以及能体现目标风格的参考照片。

  2. 生成同景参考

    调用生图模型，按原片的构图试出接近参考照片的色调与明暗。

  3. 把色彩迁移回原片

    将原片和生成的同景参考交给 GradeMirror，由它在原片上应用调色效果并按原尺寸导出。

基于 GradeMirror 的调色 Skill 正在开发中，敬请期待。查看 CLI 用法 ↗

PowerShell
# 检查版本、运行时和设备
.\GradeMirror-CLI.exe doctor --json

# 检查一个保存工程的 CPU 重放路线
.\GradeMirror-CLI.exe plan --project ".\example.grademirror" `
  --operation replay --backend cpu --json

# 用生成的同景参考为原片仿色，并按原尺寸导出
.\GradeMirror-CLI.exe fit --source ".\original.tif" `
  --reference ".\reference.png" --mode fast --backend auto `
  --out ".\new.grademirror" --export ".\matched.tif" `
  --alpha 0.75 --json
plan / fit / refine / replay
规划、首次仿色、继续精细处理、恢复保存工程。
submit / status / events / cancel
提交任务、查询状态与事件、取消执行。任务和执行尝试可分别标识。
result preview / export / release
读取预览、指定强度导出、释放内存中保留的结果。各命令可使用 --help 查看参数。
