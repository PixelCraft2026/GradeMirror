This 480-byte sRGB fallback profile is the unmodified Qt 6.10.1 named sRGB
profile obtained with QColorSpace(QColorSpace.SRgb).iccProfile(). QtBase
qicc.cpp emits the ICC creator version bytes. It is fixed solely for
GradeMirror's previously untagged desktop import preview. It is not proof
that a file carried an embedded profile.
