# GradeMirror preview.50 · Windows x64 便携版

完整解压 CPU ZIP，或将两个 GPU ZIP 分别解压到同一目标目录。进入程序目录并运行 `GradeMirror.exe`。
可用 `GradeMirror-CLI.exe doctor --json` 获取实际版本、角色和设备枚举。
工作数据写入 `%LOCALAPPDATA%/GradeMirror/LightPreview`。保留相片原件及对应工程。
设备枚举和模型前角色探针只覆盖启动，执行仍受产品资源门约束。

「帮助」菜单提供设备与运行状态以及重新定位原图。任务开始后，底栏显示已收到的阶段和进度，
有足够数据时才显示用时估计。使用同版工程源码和材料包查看构建与许可。
上游署名及第三方条款随相应材料保留。GradeMirror 自有部分署名 PixelCraft2026。
